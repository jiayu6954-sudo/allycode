# 发送给 AllyCode 的完整任务

你正在从零交付一个工业化的全渠道电商自动化平台 OmniTrade。请完整读取本目录的 README、REQUIREMENTS、API_CONTRACT、EVALUATION 和 `.challenge` 中的公开验收器，再开始实现。

执行要求：

1. 先使用可见工作计划拆分架构、后端领域、网络集成、前端、测试和验收，任何时刻最多一个步骤处于进行中；
2. 不得修改 `.challenge/`、REQUIREMENTS.md、API_CONTRACT.md、EVALUATION.md 来绕过测试；
3. 允许选择合理的 TypeScript/JavaScript 技术栈，但必须在 Windows + Node.js 22 上通过一条命令启动，不能依赖云账号或真实付费服务；
4. 实现商品同步与发布、定价、库存预占、订单状态机、支付/物流 Webhook、客服、成交回访、领域钩子、审计、异步作业、业务缓存、外部 API 重试和 ETag；
5. 实现简洁专业的中文管理前端，包含总览、商品、订单、客服、自动化页面以及加载、空、错误状态；
6. 对输入、金额、状态转换、Webhook 签名、幂等键和敏感数据日志进行安全处理；
7. 自己编写单元、集成和端到端测试；不要只依赖挑战验收器；
8. `npm run start:test` 必须长期运行并同时提供 `http://127.0.0.1:4300` API 和 `http://127.0.0.1:4173` Web；
9. 完成前直接运行 `node .challenge/run-all.mjs`，根据失败证据修复，直到通过或明确报告真实阻塞；
10. 最终汇报必须包含架构、修改文件、运行命令、测试结果、挑战得分、缓存指标、已知限制和没有完成的部分。没有真实命令证据时不得声称通过。

这是长任务。必须依赖文件、计划、检查点和测试维持连续性，不要在对话里重复粘贴大段源代码。
