# AllyCode Linux 安装与使用

alpha.22 首轮验证基线为 Ubuntu 24.04 x86_64、X11 图形会话。Linux 接通了文档、表格公式、OCR、图片与 PDF 渲染、本地视觉模型及桌面控件桥接；不能据此宣称所有发行版、ARM 和 Wayland 操作已完整验收。

## 普通用户的开始步骤

1. 优先安装发行包 `AllyCode-0.11.0-alpha.22-amd64.deb`。在系统安装器中打开并确认安装。若桌面未关联 DEB 安装器，可在该文件所在目录执行 `sudo apt install ./AllyCode-0.11.0-alpha.22-amd64.deb`，由 apt 解析系统依赖。
2. 从应用菜单打开 AllyCode，进入“开始设置”。连接模型并填写自己的 API 凭据；邮箱注册是可选项，与模型服务分开。
3. 点击“安装办公与识别组件”，根据系统提示授权。首次联网准备 Python 文档库与转换引擎；已有 Chrome/Chromium 可直接使用，没有时在用户数据目录安装独立浏览器。保留所有高级设置、工具、插件入口。
4. 选择项目文件夹，用自然语言描述工作。历史任务继续在原任务中打开；新任务保持独立任务记忆。
5. 如需完整图片理解，再展开视觉组件，安装 Qwen3.5-9B 与 PaddleOCR-VL-1.6。两模型和运行时下载合计约 9.86 GB，Linux 还预留约 10 GiB 解压运行空间。网络与硬件决定准备时间；普通文字办公无需先下载模型。

API、邮件服务和下载需要网络。模型 API 是否收费由供应商决定。组件安装只准备环境，不自动处理用户的票据或业务文件。

## 文件位置与办公兼容

默认数据位于 `~/.allycode`，组件在其 `components` 子目录；设置 `ALLYCODE_DATA_DIR` 可由部署者更改。`ALLYCODE_DOCUMENT_HOME` 与 `ALLYCODE_VISION_HOME` 仍支持独立组件路径。任务输出保存在所选项目目录，账号登录不迁移这些文件。

Ubuntu 自带 LibreOffice 24.2 在真实 XLOOKUP 回归中报 `#NAME?`。安装流程因此补充独立 LibreOffice 26.2.6；解包在用户组件目录，不替换系统办公软件。固定下载包 SHA256 为 `fd0e8f8f2408dd2e5b90286e60f3f97cf566ba441cd48cfc5bcc68067303e0bc`。该值来自本轮 HTTPS 发行镜像下载的文件计算；官方校验页本轮超时，未宣称独立完成发布者摘要复核。哈希不一致拒绝解包。

Linux OCR 使用 Tesseract 中英文语言包；视觉理解使用与 Windows 相同的固定模型权重。OCR 数据仍需核对金额、票号、页覆盖与业务含义，不自动成为已审核数据。商业公文字体需要合法授权并安装；Noto CJK 是通用中文支持，不能替代精确字体验收。

## 平台边界

- X11：已验证 AT-SPI 窗口枚举、控件识别、输入、点击、截图及固定快捷键。无法访问的控件不伪造成功。本轮 Electron 自身窗口在 AT-SPI 中未枚举到，但 X11 窗口和界面截图正常；GTK 桥接通过不能推导为任意软件都可操作。
- Wayland：AT-SPI 可能支持控件操作，但当前全局快捷键与截图没有接入授权门户，会明确拒绝并提示切换 X11 或使用浏览器验证；尚未全量验收。
- Chromium/Electron 需要系统允许相应沙箱机制。应用不自动添加 `--no-sandbox`。Docker 测试使用独立容器调整 seccomp 以支持浏览器沙箱，这不代表普通用户应关闭安全机制。
- AppImage 是可选便携形式，受发行版 FUSE、用户命名空间和沙箱策略影响；优先采用 DEB。其他发行版需自行补齐依赖，不宣称自动安装通用。
- Linux x64 本地模型已验证合成图；ARM、无图形桌面、真实各行业发票、跨机器环境与长期稳定性仍需专项测试。
- 精确字体、真实打印、付费模型连接、邮件送达和公网发布不包含在软件回归通过范围。

## 开发与构建

Linux 源码构建需 Node.js 22.13+、npm、Python 3.12（本轮基线）及系统构建依赖（包括 xz-utils、binutils）；普通用户使用已构建包不需要安装 Node.js。`npm ci` 后执行 `npm run desktop:linux`，输出 DEB/AppImage 到 `release/linux`。仓库 CI 已增加 Linux 办公组件、公式引擎与安装包构建，远端 CI 本轮未触发。

本轮验证使用 Ubuntu 24.04 隔离容器，保留 Windows 专项测试的合理跳过，实际运行 Linux 文档、公式、浏览器与视觉。公开验证口径见 [公开版本说明](PUBLIC_RELEASE.md)。原始本机验收附件不随源码发布。
