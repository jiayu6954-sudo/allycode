## 仍需验证与已知限制

- 当前默认模型与能力目录是代码登记值；供应商准入、真实工具调用、流式输出、计量和最新规格需要按账号逐项确认。
- 不宣称已接通语义检索，也不宣称上下文压缩可以无限、无损地保存所有信息。
- Word 精确字体、打印/PDF 目视效果需单独验收；PDF 转 Word 是可编辑内容重建，不是无损还原。
- 公式验证比对给定预期值；错误预期可被阻断，但错误业务口径仍需独立核对。
- 邮箱账号不等于企业权限治理、云同步或同一 OS 用户内的多租户隔离。
- 正式代码签名、公开更新基础设施、跨版本回滚与大规模安装未完整验收。
- 依赖审计应以 `npm audit` 的当前结果为准，不将测试通过写成“无安全漏洞”。
