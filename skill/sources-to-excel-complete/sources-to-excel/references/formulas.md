# 行业数据理解与 Excel 函数公式（内置）

适用于用户需要 Excel 计算或分析交付的任务。行业不设固定白名单，也不承诺对所有行业都准确。先识别字段含义、实体、单位、日期区间、主键、缺失、重复、合计与明细，再按用户目标设计表格和计算。财务、电商、库存、科研等是示例，不能强制套用某一行业列名。

## 执行规则

1. 按资料自动识别字段和数据类型。编号、税号、商品编码等保留文本和前导零；金额用十进制；不把缺失当零、空字符串当数值。格式或名词相同不代表业务含义相同。
2. 字段存在同义词、不同币种、含税/不含税、退款/取消、不同期间时先明确计算口径。清晰的口径自行执行；重大歧义才提问。税率、会计口径、行业指标阈值等不能臆造。
3. 可从原字段计算的指标保留 Excel 公式，不只交付写死的结果。例如销售额=数量×单价，毛利额=收入−成本；是否扣退款、税费、平台费由资料和用户目标决定。这些是计算示例，不是全行业强制业务规则。
4. 自行确定工作表、列、行粒度、汇总和关联关系，并保留 rowMeaning/designReason。简单任务不强迫用户选模板；复杂任务分层整理，不把多种实体硬塞一张表。
5. 先用确定性计算或独立核对得到 expected，再交由本地 Calc 重算比对。不能从错误公式复制一个猜测结果作为 expected，不能为了通过验收改掉 expected。IFERROR 不得用来掩盖缺失、除零或口径问题；只有业务明确允许时才返回 0，否则标记待核实。

## 工具协议

仍使用 sources_to_excel build。原始文本 type=text，即使以 = 开头也保持文本。只有显式 type=formula 的列会生成可执行公式。

```json
{
  "columns": [
    {"key":"qty","header":"数量","type":"integer"},
    {"key":"unit_price","header":"单价","type":"decimal"},
    {"key":"revenue","header":"销售额","type":"formula"}
  ],
  "rows": [{
    "values": {
      "qty":"3",
      "unit_price":"100.00",
      "revenue":{
        "formula":"=ROUND(A2*B2,2)",
        "resultType":"decimal",
        "expected":"300.00",
        "tolerance":"0.000001",
        "numberFormat":"0.00",
        "explanation":"数量乘单价；仅计算资料中的销售额，未擅自扣除税费或退款"
      }
    }
  }]
}
```

此片段只展示列和值；实际请求仍必须有 manifest、output、coverage、sheets，以及每个非空字段的 evidence。公式字段 evidence 指向参与计算的原始数据，不能只引用最终答案文字。缺少值的公式不得编造输入；可拆为待核实表或先处理完整记录。

resultType 支持 decimal、integer、text、boolean；数值 expected 传十进制字符串或整数，不传浮点数。默认绝对误差 0.000000001，可设 0 至 0.01；不为过关扩大误差。百分比用真实比例数值配合 numberFormat="0.00%"，不要把 20% 与 20 混用。

## 当前函数范围

- 汇总：SUM、AVERAGE、COUNT、COUNTA、MIN、MAX、SUMPRODUCT、SUBTOTAL。
- 条件：IF、IFERROR、AND、OR、NOT、SUMIF、SUMIFS、COUNTIF、COUNTIFS、AVERAGEIF、AVERAGEIFS。
- 查找：VLOOKUP、HLOOKUP、INDEX、MATCH、XLOOKUP。
- 数值：ROUND、ROUNDUP、ROUNDDOWN、ABS，以及四则运算、比较与百分号。
- 日期分解和文本：DATE、YEAR、MONTH、DAY、LEN、LEFT、RIGHT、MID、TRIM、CONCATENATE、TEXT。日期序列值与字符串要区别；不把字符串当已验证日期。

函数名用英文、参数用逗号；单元格用 A1 引用，支持 $ 绝对引用及本工作簿跨表有限区域。不支持整列区域、名称/结构化引用、动态数组、宏/VBA、自定义函数、INDIRECT、OFFSET、外部工作簿及联网函数。不能为了绕过限制把外部公式拼到普通数据里。遇到不支持公式时明确范围，用受支持函数重构或提出后续能力需求。

单批最多 10000 个公式，总依赖引用最多 200 万格；超出分批，不截断资料。循环引用和越界在执行前阻止；除零等错误、缓存缺失、与独立预期值不一致均不发布最终文件。

## 重算与交付

status 返回 formulaEngineReady。缺失时用 document_format setup 安装已固定版本与哈希的 LibreOffice，依权限流程进行；用户无需自己编写公式脚本。

工具在独立暂存目录生成工作簿，用本地 Calc 实际重算，再核对所有公式值；只把验证后的缓存写回原样式工作簿，不直接交付 Calc 改写的排版。成功后一次性发布新的 xlsx 和 audit.json，保留可编辑公式、缓存值、口径、预期值及实际值。不覆盖已有文件。失败的暂存工作簿不是交付物。

旧 Excel 可读取公式与已有缓存，但不能把缓存当成最新计算结果。当前重算链路针对本工具新生成的受支持公式工作簿；任意旧复杂工作簿、宏、图表、外链、Excel/WPS 专有函数没有全部兼容承诺。需要保留原复杂工作簿时先说明范围，不把扁平重建称为无损编辑。

系统证明的是：公式在当前本地引擎实际算出了与给定预期相符的值，文件可重新读取；业务口径、来源识别及模型字段理解仍需独立核对。不要声称跨行业识别准确率 100%，不要把结构测试当真实行业数据评测。
